# Learning

Structured, sequential courses with exercises and checkpoints.

This is distinct from the other places knowledge lives in this repository:

| Directory | What it is |
| --- | --- |
| **`learning/`** | **Structured courses.** Theory, examples, exercises, checkpoints. Worked through in order |
| [`notes/`](../notes/README.md) | Reference notes per domain. Written as understanding accumulates, read non-linearly |
| [`fundamentals/`](../fundamentals/README.md) | GPU programming exercises, each through the measure-profile-optimize loop |
| `c-lessons/` | Guided C files with a read-predict-run method (separate track, if present) |

`learning/` is for material that has a **beginning and an end** and gates progress. Everything in it maps to a phase of the [roadmap](../ROADMAP.md).
