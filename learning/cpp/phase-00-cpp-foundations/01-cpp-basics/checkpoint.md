## 📘 Theory

- [ ] I can explain why `sizeof(int)` is known at compile time and costs nothing at run time
- [ ] I can explain what `#include` actually does, and why it is not `import`
- [ ] I can explain the difference between declaration and initialization, and what an uninitialized local holds
- [ ] I can explain why `int x = 3.9;` compiles and what `int x{3.9};` does instead
- [ ] I can explain what happens when a signed `int` exceeds its maximum
- [ ] I can explain why `7 / 2` is `3` and where the cast must go to fix it
- [ ] I can explain the difference between scope and lifetime
- [ ] I can explain why `float` is preferred over `double` in GPU code

## 🔬 Mastery

- [ ] I can predict the output of an unfamiliar program mixing integer division, casts and overflow — **before** running it
- [ ] I can look at a variable declaration and state how many bytes it occupies and where it lives
- [ ] Given a program that prints something unexpected, I can find the type-related cause
- [ ] I can explain, without notes, why C++ is faster than Python for numeric loops
- [ ] I can compute the memory footprint of an array of N elements of a given type in my head
- [ ] I can apply this to a problem I have not seen: given a tensor shape and dtype, state its size in MB
