# Review

Cumulative quizzes. **Deliberately not organized by module.**

## Why cumulative

Finishing the pointers module and then answering pointer questions tests recall over a few hours. That is not what is needed. What is needed is answering a pointer question three weeks later, mixed in with type questions and layout questions, without being told which is which.

That is spaced repetition, approximated with the tools available: each quiz revisits everything up to that point, with the older material weighted more heavily.

## When to take them

| Quiz | After module | Covers |
| --- | --- | --- |
| [quiz-01.md](quiz-01.md) | 02 | Basics, functions |

| [quiz-03.md](quiz-03.md) | 06 | Everything through memory |
| [quiz-04.md](quiz-04.md) | 08 | Everything — the full-phase review |

Then, later: **retake quiz-02 a week after finishing it.** If the score drops, that is real information about what was memorized rather than understood.

## Rules

- **Closed book.** No notes, no compiler, no searching.
- Write the answers out. Recognizing an answer is not the same as producing one.
- For prediction questions, commit in writing before checking.
- Score honestly.

## Scoring

| Score | Meaning |
| --- | --- |
| Below 70% | Reread the theory for the weak areas before continuing |
| 70–85% | Continue, and note the gaps |
| Above 85% | Solid |

Below 70% is not failure — it is the quiz doing its job. Continuing on top of a gap is what costs time.
